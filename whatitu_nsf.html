📊 WHATITU Naive Seasonal Forecaster HELPER

Prediksi data deret waktu (time series) menggunakan WHATITU Naive Seasonal Forecaster secara otomatis. Semua proses berjalan di browser Anda.

Aplikasi ini menggunakan pendekatan estimasi Yule-Walker & OLS iteratif untuk pemrosesan cepat 100% client-side. Hasil kalkulasi merupakan simulasi dan aproksimasi cepat. Untuk kebutuhan analisis ilmiah, riset akademis akhir, atau keputusan finansial berisiko tinggi, selalu gunakan engine komputasi berbasis Maximum Likelihood Estimation / MLE (seperti Statsmodels / Darts di Python).

📥 Input Data
Pisahkan angka menggunakan spasi, koma, titik koma, tab, atau slash.
Minimal 24 data diperlukan.
⚙️ Parameter WHATITU Naive Seasonal Forecaster
Pilih jenis data untuk mengatur periode musiman (m) secara otomatis.
? Menentukan berapa banyak data sebelumnya yang digunakan sebagai acuan.
Auto Regression — berapa data sebelumnya dijadikan acuan. Biasanya 0–3.
? Menstabilkan data yang terus naik atau turun. Biasanya 0–2.
Differencing — 0 = stabil, 1 = cukup, 2 = tren sangat kuat.
? Memperbaiki prediksi berdasarkan kesalahan sebelumnya. Biasanya 0–2.
Moving Average — memperbaiki prediksi dari error sebelumnya.
? Sama seperti p, tetapi untuk pola musiman (berulang setiap m periode).
Seasonal AR — acuan data pada pola musiman. Biasanya 0–1.
? Menstabilkan pola musiman yang memiliki tren.
Seasonal Differencing — stabilkan tren musiman. Biasanya 0–1.
? Memperbaiki error pada pola musiman.
Seasonal MA — koreksi error musiman. Biasanya 0–1.
? Jumlah periode dalam satu siklus musim. Misal: bulanan=12, mingguan=52, harian=7.
Periode musiman — bulanan=12, mingguan=52, harian=7, kuartalan=4.
ℹ️ Pengaturan Aman Diterapkan Parameter default ini cocok untuk banyak data bulanan. Jika hasil prediksi kurang baik, Anda dapat mencoba mengubah parameter secara bertahap.
💡 Tips: Tidak ada satu kombinasi parameter WHATITU Naive Seasonal Forecaster yang selalu paling baik. Jika hasil prediksi kurang akurat, cobalah beberapa kombinasi parameter dan bandingkan nilai MAPE. Semakin kecil nilai MAPE, umumnya semakin baik performa model.
