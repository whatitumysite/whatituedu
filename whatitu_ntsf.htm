📊 WHATITU Naive Time Series Forecaster HELPER

Aplikasi ini menggunakan aproksimasi Yule-Walker & OLS sederhana di sisi klien untuk simulasi cepat. Untuk kebutuhan analisis ilmiah, riset akademis akhir, atau keputusan finansial berisiko tinggi, selalu gunakan engine komputasi berbasis MLE (seperti Statsmodels/Darts di Python).

📝 Input Data
Pisahkan data dengan spasi, koma, titik koma, atau slash. Minimal 20 data.
⚙️ Parameter WHATITU Naive Time Series Forecaster
? Menentukan berapa banyak data sebelumnya yang dijadikan acuan untuk memprediksi data berikutnya. Jika tidak yakin, gunakan 1.
? Digunakan untuk membuat data lebih stabil jika memiliki tren. 0 = data stabil, 1 = paling umum, 2 = tren sangat kuat.
? Memperbaiki prediksi berdasarkan kesalahan pada periode sebelumnya. Biasanya cukup antara 0–2.
🔮 Forecast Step
Masukkan bilangan bulat positif (1–100).
